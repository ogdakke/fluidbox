# @ogdakke/fluidbox

A custom-element lightbox with indexed galleries. The package exports browser elements, explicit CSS, and separate React, Solid, Vue, and Angular bindings.

```ts
import "@ogdakke/fluidbox/elements";
import "@ogdakke/fluidbox/styles.css";
```

For server rendering, import `@ogdakke/fluidbox` or a framework subpath and register elements after mount. `@ogdakke/fluidbox/elements` requires a browser.

The package is private while its API is being developed. The source repository includes a markup guide and working examples for all four bindings.
