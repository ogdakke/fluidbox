Custom elements

Elements

Register once with @ogdakke/fluidbox/elements, then write markup. Galleries, filmstrips, and indexed sources need no framework.

01  dom gallery

Plain markup, any aspect ratio

<fluidbox-gallery> collects every <fluidbox-item> inside it. The rounded trigger is the handoff box, so its corners carry through the flight.

Markup 
<script type="module">
  import "@ogdakke/fluidbox/elements";
  import "@ogdakke/fluidbox/styles.css";
</script>

<fluidbox-gallery aria-label="Landscapes">
  <fluidbox-item item-id="dune">
    <button slot="trigger" type="button" data-fluidbox-preview>
      <img src="/art/dune.svg" alt="Dune at golden hour" width="1800" height="1200" />
    </button>
    <template slot="content">
      <img src="/art/dune.svg" alt="Dune at golden hour" width="1800" height="1200" />
    </template>
    <span slot="caption">Dune at golden hour</span>
  </fluidbox-item>
  <!-- …more items -->
  <fluidbox-filmstrip></fluidbox-filmstrip>
</fluidbox-gallery>

02  indexed source

100,000 items, 12 thumbnails in the DOM

A FluidboxSource describes the collection by index. The page renders only the cards it shows; an origin adapter tells the viewer where each one is.

Source and origins 
gallery.source = {
  count: 100_000,
  getItem: (index) => ({ id: String(index), media: { type: "image", src, width, height } }),
  getIndex: (id) => Number(id),
};
gallery.origins = {
  getOrigin(id) {
    const trigger = mountedCards.get(id);
    return trigger ? { trigger, visual: trigger.querySelector("[data-fluidbox-origin]") } : null;
  },
};
gallery.open({ index: 49_999 });
