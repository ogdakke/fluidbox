@ogdakke/fluidbox/react

React

Composed parts over the same runtime. Any element can be the origin, one trigger can stand in for an album, and a virtualizer can host a hundred thousand photos.

01  origins

Any element can be the origin

The image can sit inside a richer card, a static map can open a live one, and a text card can stand in for a whole album.

Composition 
import { Fluidbox } from "@ogdakke/fluidbox/react";

<Fluidbox.Root items={photos}>
  <Fluidbox.Trigger item={photos[0]} items={photos} asChild>
    {({ item }) => (
      <button type="button">
        <img src={item?.thumbnail?.src} alt="" data-fluidbox-origin />
        <Fluidbox.ThumbnailOverlay>+{photos.length - 1}</Fluidbox.ThumbnailOverlay>
      </button>
    )}
  </Fluidbox.Trigger>
  <Fluidbox.Portal>
    <Fluidbox.Previous /> <Fluidbox.Next /> <Fluidbox.Close />
    <Fluidbox.Filmstrip />
  </Fluidbox.Portal>
</Fluidbox.Root>
