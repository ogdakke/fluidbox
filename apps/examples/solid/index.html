useFluidboxGallery(source) returns a ref callback that keeps an <fluidbox-gallery> in sync with a signal.

01  source switching

Switch the source

The binding writes a new source to the gallery. The next open uses the new collection and the thumbnails follow.

Binding 
const [source, setSource] = createSignal(photos);
const bind = useFluidboxGallery(source);

<fluidbox-gallery ref={(node) => { gallery = node; bind(node); }}>
  <For each={items()}>
    {(item, index) => <button onClick={() => gallery.open({ index: index() })}>…</button>}
  </For>
</fluidbox-gallery>
