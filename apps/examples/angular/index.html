@ogdakke/fluidbox/angular

Angular

useFluidboxGallery() runs in a constructor and writes a signal's source after each render. Zoneless, no Angular library build step.

01  source switching

Switch the source

The binding writes a new source to the gallery. The next open uses the new collection and the thumbnails follow.

Binding 
@Component({ schemas: [CUSTOM_ELEMENTS_SCHEMA], template: `<app-gallery>…</app-gallery>` })
class Photos {
  readonly source = signal(photos);
  constructor() {
    useFluidboxGallery(() => this.host.nativeElement.querySelector("app-gallery"), this.source);
  }
}
